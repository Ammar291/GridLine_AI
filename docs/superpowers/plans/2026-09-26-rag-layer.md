# RAG Layer Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the pgvector-backed retrieval layer of GridLine AI: corpus loading, chunking, embeddings, filtered semantic search with verified citations, an ingest command, a ~34-document synthetic Nandipur corpus, tests and docs.

**Architecture:** One Python package `backend/gridline` with `config`, `db` (engine, two mapped tables, schema creation) and `rag` (corpus loader → chunker → embedder → `ChunkStore` on pgvector → `Retriever`). Citation IDs are chunk IDs (`doc-slug#section`), so every citation is a real row. Embedding provider is pluggable (`fastembed` local ONNX model or a deterministic `hashed` fallback); tests use `hashed` so they run offline.

**Tech Stack:** Python 3.13, uv, SQLAlchemy 2.x async + psycopg 3, pgvector (Postgres 16 in Docker), Pydantic v2, pydantic-settings, PyYAML, numpy, fastembed, pytest + pytest-asyncio, pyright strict, ruff.

**Spec:** `docs/superpowers/specs/2026-09-26-rag-layer-design.md` (read it first; this plan argues from it).

## Global Constraints

- Synthetic data only: no real places, people or organisations. **No names of individuals anywhere in the corpus.**
- One process, one database (PostgreSQL + pgvector). No second runtime, no in-memory fallback store.
- No LLM calls in this layer. Retrieval is embedding similarity only.
- Runs offline: `EMBEDDING_PROVIDER=hashed` needs no downloads; `auto` falls back to it.
- Every citation refers to a stored chunk; nothing is fabricated. Empty results are `[]`.
- Backend: fully typed, `pyright` strict on `gridline/`, `ruff check` clean, Pydantic v2 at every boundary, SQLAlchemy 2.x typed mapped classes, async on the request path, no module-level mutable state, files under ~300 lines.
- Database host port is **5433** (5432 is occupied on the dev machine). `DATABASE_URL=postgresql+psycopg://gridline:gridline@localhost:5433/gridline`, `TEST_DATABASE_URL=...:5433/gridline_test`.
- Windows dev machine: psycopg async needs a selector event loop. Tests set it via an `event_loop_policy` fixture; the CLI uses `asyncio.Runner(loop_factory=asyncio.SelectorEventLoop)` on `win32`.
- All commands run from `backend/` with `uv run ...`. Do not commit; the user commits.
- Domain naming: zone, channel, project, crew, incident, document, chunk, citation. No synonyms.

## Review Focus

1. A corpus file with a duplicate `slug` or an unknown `kind`/`zone_id`/`hazard` must fail ingestion loudly before any DB write (Task 3 tests `test_duplicate_slug_raises`, `test_unknown_zone_raises`).
2. A heading that repeats inside one document (two "## Notes" sections) must not collide on chunk ID (Task 4 test `test_duplicate_headings_get_suffixes`).
3. A chunk with empty `hazards`/`zone_ids` (city-wide) must still match a hazard/zone filter; a chunk with a different hazard must not (Task 7 tests `test_search_hazard_filter_excludes_other_hazard`, `test_search_city_wide_chunk_matches_zone_filter`).
4. Re-ingesting an unchanged corpus must keep chunk IDs identical so stored citations stay valid; an edited file must drop its old chunk IDs (Task 9 tests `test_reingest_unchanged_is_noop`, `test_edited_document_replaces_chunks`).
5. Retrieval with an embedder different from the one used at ingest must refuse, not return nonsense similarities (Task 8 test `test_retrieve_refuses_mismatched_embedder`).

```python
from sqlalchemy.ext.asyncio import AsyncEngine, AsyncSession, async_sessionmaker, create_async_engine


def create_engine(url: str, *, echo: bool = False) -> AsyncEngine:
    return create_async_engine(url, echo=echo, pool_pre_ping=True)


def session_factory(engine: AsyncEngine) -> async_sessionmaker[AsyncSession]:
    return async_sessionmaker(engine, expire_on_commit=False)
```

```python
"""SQLAlchemy mapped classes for the RAG corpus (ARCHITECTURE.md §4: documents, chunks)."""

from datetime import date, datetime
from typing import Any

from pgvector.sqlalchemy import Vector
from sqlalchemy import Date, DateTime, ForeignKey, Index, Integer, Text, func
from sqlalchemy.dialects.postgresql import ARRAY, JSONB
from sqlalchemy.orm import DeclarativeBase, Mapped, mapped_column, relationship

EMBEDDING_DIMENSION = 384


class Base(DeclarativeBase):
    pass


class Document(Base):
    __tablename__ = "documents"

    id: Mapped[str] = mapped_column(Text, primary_key=True)
    title: Mapped[str] = mapped_column(Text, nullable=False)
    kind: Mapped[str] = mapped_column(Text, nullable=False, index=True)
    source: Mapped[str] = mapped_column(Text, nullable=False)
    source_path: Mapped[str] = mapped_column(Text, nullable=False)
    date: Mapped[date | None] = mapped_column(Date, nullable=True)
    zone_ids: Mapped[list[str]] = mapped_column(ARRAY(Text), nullable=False, default=list)
    hazards: Mapped[list[str]] = mapped_column(ARRAY(Text), nullable=False, default=list)
    content_hash: Mapped[str] = mapped_column(Text, nullable=False)
    embedding_model: Mapped[str] = mapped_column(Text, nullable=False)
    metadata_: Mapped[dict[str, Any]] = mapped_column("metadata", JSONB, nullable=False, default=dict)
    ingested_at: Mapped[datetime] = mapped_column(DateTime(timezone=True), nullable=False, server_default=func.now())

    chunks: Mapped[list["Chunk"]] = relationship(back_populates="document", cascade="all, delete-orphan")


class Chunk(Base):
    __tablename__ = "chunks"
    __table_args__ = (
        Index(
            "ix_chunks_embedding_hnsw",
            "embedding",
            postgresql_using="hnsw",
            postgresql_with={"m": 16, "ef_construction": 64},
            postgresql_ops={"embedding": "vector_cosine_ops"},
        ),
    )

    id: Mapped[str] = mapped_column(Text, primary_key=True)
    document_id: Mapped[str] = mapped_column(ForeignKey("documents.id", ondelete="CASCADE"), nullable=False, index=True)
    section_id: Mapped[str] = mapped_column(Text, nullable=False)
    section_title: Mapped[str] = mapped_column(Text, nullable=False)
    position: Mapped[int] = mapped_column(Integer, nullable=False)
    text: Mapped[str] = mapped_column(Text, nullable=False)
    embedding: Mapped[list[float]] = mapped_column(Vector(EMBEDDING_DIMENSION), nullable=False)
    kind: Mapped[str] = mapped_column(Text, nullable=False, index=True)
    zone_ids: Mapped[list[str]] = mapped_column(ARRAY(Text), nullable=False, default=list)
    hazards: Mapped[list[str]] = mapped_column(ARRAY(Text), nullable=False, default=list)
    metadata_: Mapped[dict[str, Any]] = mapped_column("metadata", JSONB, nullable=False, default=dict)

    document: Mapped[Document] = relationship(back_populates="chunks")
```

`schema.py`:

```python
"""Schema management. No Alembic: tables are created at startup (ARCHITECTURE.md §4)."""

from sqlalchemy import text
from sqlalchemy.ext.asyncio import AsyncEngine

from gridline.db.models import Base


async def create_schema(engine: AsyncEngine) -> None:
    async with engine.begin() as conn:
        await conn.execute(text("CREATE EXTENSION IF NOT EXISTS vector"))
        await conn.run_sync(Base.metadata.create_all)


async def drop_schema(engine: AsyncEngine) -> None:
    async with engine.begin() as conn:
        await conn.run_sync(Base.metadata.drop_all)


async def truncate_corpus(engine: AsyncEngine) -> None:
    async with engine.begin() as conn:
        await conn.execute(text("TRUNCATE TABLE documents CASCADE"))
```

```python
def test_content_hash_changes_with_content(tmp_path):
    src = (FIXTURES / "test-fire-sop.md").read_text(encoding="utf-8")
```

```python
"""Load Markdown documents with YAML front matter from the corpus directory."""

import hashlib
import re
from datetime import date
from pathlib import Path
from typing import Any

import yaml
from pydantic import ValidationError

from gridline.rag.models import HAZARDS, ZONE_IDS, CorpusDocument, CorpusError, DocumentKind

FRONT_MATTER = re.compile(r"\A---\r?\n(.*?)\r?\n---\r?\n(.*)\Z", re.DOTALL)
SLUG = re.compile(r"^[a-z0-9][a-z0-9-]*$")
REQUIRED = ("title", "slug", "kind", "source")
KNOWN = {"title", "slug", "kind", "source", "date", "zone_ids", "hazards"}


def parse_document(path: Path, root: Path) -> CorpusDocument:
    raw = path.read_text(encoding="utf-8")
    rel = path.relative_to(root).as_posix()
    match = FRONT_MATTER.match(raw)
    if match is None:
        raise CorpusError(rel, "missing YAML front matter block")
    try:
        loaded: object = yaml.safe_load(match.group(1))
    except yaml.YAMLError as exc:
        raise CorpusError(rel, f"invalid YAML front matter: {exc}") from exc
    if not isinstance(loaded, dict):
        raise CorpusError(rel, "front matter must be a mapping")
    meta: dict[str, Any] = {str(k): v for k, v in loaded.items()}  # pyright: ignore[reportUnknownVariableType]
    for key in REQUIRED:
        if not meta.get(key):
            raise CorpusError(rel, f"missing required front matter field '{key}'")
    slug = str(meta["slug"])
    if not SLUG.match(slug):
        raise CorpusError(rel, f"slug '{slug}' must match {SLUG.pattern}")
    try:
        kind = DocumentKind(str(meta["kind"]))
    except ValueError as exc:
        raise CorpusError(rel, f"unknown kind '{meta['kind']}'; expected one of {sorted(DocumentKind)}") from exc
    zone_ids = _str_list(meta.get("zone_ids"), rel, "zone_ids")
    hazards = _str_list(meta.get("hazards"), rel, "hazards")
    if unknown := set(zone_ids) - ZONE_IDS:
        raise CorpusError(rel, f"unknown zone_ids {sorted(unknown)}; expected subset of {sorted(ZONE_IDS)}")
    if unknown := set(hazards) - HAZARDS:
        raise CorpusError(rel, f"unknown hazards {sorted(unknown)}; expected subset of {sorted(HAZARDS)}")
    doc_date = meta.get("date")
    if doc_date is not None and not isinstance(doc_date, date):
        raise CorpusError(rel, "date must be an ISO date (YYYY-MM-DD)")
    extra = {k: v for k, v in meta.items() if k not in KNOWN}
    try:
        return CorpusDocument(
            slug=slug,
            title=str(meta["title"]),
            kind=kind,
            source=str(meta["source"]),
            source_path=rel,
            date=doc_date,
            zone_ids=zone_ids,
            hazards=hazards,
            metadata=extra,
            body=match.group(2),
            content_hash=hashlib.sha256(raw.encode("utf-8")).hexdigest(),
        )
    except ValidationError as exc:
        raise CorpusError(rel, str(exc)) from exc


def load_corpus(corpus_dir: Path) -> list[CorpusDocument]:
    if not corpus_dir.is_dir():
        raise CorpusError(str(corpus_dir), "corpus directory not found")
    docs = [parse_document(p, corpus_dir) for p in sorted(corpus_dir.rglob("*.md"))]
    seen: dict[str, str] = {}
    for doc in docs:
        if doc.slug in seen:
            raise CorpusError(doc.source_path, f"duplicate slug '{doc.slug}' (also in {seen[doc.slug]})")
        seen[doc.slug] = doc.source_path
    return sorted(docs, key=lambda d: d.slug)


def _str_list(value: object, rel: str, field: str) -> list[str]:
    if value is None:
        return []
    if not isinstance(value, list):
        raise CorpusError(rel, f"{field} must be a list")
    return [str(v) for v in value]  # pyright: ignore[reportUnknownVariableType]
```

```python
"""Split a corpus document into citable chunks with stable IDs (spec §6)."""

import re
from dataclasses import dataclass

from gridline.rag.models import ChunkDraft, CorpusDocument

HEADING = re.compile(r"^(#{1,3})\s+(.*?)\s*#*\s*$")
NUMBER_PREFIX = re.compile(r"^(\d+(?:\.\d+)*)\.?\s+(.*)$")
NON_SLUG = re.compile(r"[^a-z0-9]+")


def section_id_for(heading: str) -> str:
    m = NUMBER_PREFIX.match(heading.strip())
    if m:
        return "s" + m.group(1)
    slug = NON_SLUG.sub("-", heading.strip().lower()).strip("-")
    return slug or "section"


def strip_heading_number(heading: str) -> str:
    m = NUMBER_PREFIX.match(heading.strip())
    return m.group(2).strip() if m else heading.strip()


@dataclass
class _Section:
    section_id: str
    title: str
    paragraphs: list[str]

    @property
    def text(self) -> str:
        return "\n\n".join(self.paragraphs).strip()

    @property
    def words(self) -> int:
        return len(self.text.split())


def _parse_sections(doc: CorpusDocument) -> list[_Section]:
    sections: list[_Section] = [_Section("intro", doc.title, [])]
    buffer: list[str] = []

    def flush() -> None:
        text = "\n".join(buffer).strip()
        if text:
            sections[-1].paragraphs.append(text)
        buffer.clear()

    for line in doc.body.splitlines():
        m = HEADING.match(line)
        if m and len(m.group(1)) == 1:
            flush()  # H1 is the document title; never a section
            continue
        if m:
            flush()
            sections.append(_Section(section_id_for(m.group(2)), strip_heading_number(m.group(2)), []))
            continue
        if line.strip() == "":
            flush()
        else:
            buffer.append(line)
    flush()
    return [s for s in sections if s.paragraphs]


def _dedupe_ids(sections: list[_Section]) -> None:
    seen: dict[str, int] = {}
    for s in sections:
        n = seen.get(s.section_id, 0) + 1
        seen[s.section_id] = n
        if n > 1:
            s.section_id = f"{s.section_id}-{n}"


def _merge_short(sections: list[_Section], min_words: int) -> list[_Section]:
    merged: list[_Section] = []
    for s in sections:
        if merged and s.section_id != "intro" and s.words < min_words:
            merged[-1].paragraphs.append(f"{s.title}\n\n{s.text}")
        else:
            merged.append(s)
    return merged


def _split_long(paragraphs: list[str], max_words: int) -> list[str]:
    parts: list[str] = []
    current: list[str] = []
    count = 0
    for p in paragraphs:
        n = len(p.split())
        if current and count + n > max_words:
            parts.append("\n\n".join(current))
            current, count = [], 0
        current.append(p)
        count += n
    if current:
        parts.append("\n\n".join(current))
    return parts


def chunk_document(doc: CorpusDocument, *, max_words: int = 350, min_words: int = 25) -> list[ChunkDraft]:
    sections = _parse_sections(doc)
    _dedupe_ids(sections)
    sections = _merge_short(sections, min_words)
    chunks: list[ChunkDraft] = []
    for section in sections:
        parts = _split_long(section.paragraphs, max_words) if section.words > max_words else [section.text]
        for i, text in enumerate(parts, start=1):
            section_id = f"{section.section_id}-p{i}" if len(parts) > 1 else section.section_id
            chunks.append(
                ChunkDraft(
                    chunk_id=f"{doc.slug}#{section_id}",
                    document_id=doc.slug,
                    section_id=section_id,
                    section_title=section.title,
                    position=len(chunks),
                    text=text,
                    embedding_text=f"{doc.title} — {section.title}\n{text}",
                    metadata={
                        **doc.metadata,
                        "section_title": section.title,
                        "word_count": len(text.split()),
                        "part": i,
                        "source_path": doc.source_path,
                    },
                )
            )
    return chunks
```

```python
"""Embedding providers: local fastembed model, or a deterministic hashed fallback (spec §7)."""

import hashlib
import logging
import math
import re
from typing import Protocol

from gridline.config import EmbeddingProvider

log = logging.getLogger(__name__)

EMBEDDING_DIMENSION = 384
TOKEN = re.compile(r"[a-z0-9]+(?:\.[0-9]+)?")


class Embedder(Protocol):
    @property
    def name(self) -> str: ...

    @property
    def dimension(self) -> int: ...

    def embed_documents(self, texts: list[str]) -> list[list[float]]: ...

    def embed_query(self, text: str) -> list[float]: ...


class HashedEmbedder:
    """Feature-hashing bag of words and bigrams. Deterministic, offline, lexical rather than semantic."""

    def __init__(self, dimension: int = EMBEDDING_DIMENSION) -> None:
        self._dimension = dimension

    @property
    def name(self) -> str:
        return "hashed:v1"

    @property
    def dimension(self) -> int:
        return self._dimension

    def embed_documents(self, texts: list[str]) -> list[list[float]]:
        return [self._embed(t) for t in texts]

    def embed_query(self, text: str) -> list[float]:
        return self._embed(text)

    def _embed(self, text: str) -> list[float]:
        vec = [0.0] * self._dimension
        tokens = TOKEN.findall(text.lower())
        features = tokens + [f"{a} {b}" for a, b in zip(tokens, tokens[1:], strict=False)]
        for f in features:
            digest = hashlib.sha1(f.encode("utf-8")).digest()
            bucket = int.from_bytes(digest[:4], "big") % self._dimension
            sign = 1.0 if digest[4] & 1 else -1.0
            vec[bucket] += sign
        norm = math.sqrt(sum(x * x for x in vec))
        return [x / norm for x in vec] if norm else vec


class FastEmbedEmbedder:
    """Wraps fastembed's ONNX text embedding. The model loads on first use (one-time download)."""

    def __init__(self, model_name: str) -> None:
        self._model_name = model_name
        self._model: object | None = None

    @property
    def name(self) -> str:
        return f"fastembed:{self._model_name}"

    @property
    def dimension(self) -> int:
        return EMBEDDING_DIMENSION

    def warm_up(self) -> None:
        from fastembed import TextEmbedding  # imported lazily: heavy, optional at runtime

        if self._model is None:
            self._model = TextEmbedding(model_name=self._model_name)

    def _get(self) -> object:
        self.warm_up()
        assert self._model is not None
        return self._model

    def embed_documents(self, texts: list[str]) -> list[list[float]]:
        from fastembed import TextEmbedding

        model = self._get()
        assert isinstance(model, TextEmbedding)
        return [[float(x) for x in vec] for vec in model.embed(texts)]

    def embed_query(self, text: str) -> list[float]:
        from fastembed import TextEmbedding

        model = self._get()
        assert isinstance(model, TextEmbedding)
        return [[float(x) for x in vec] for vec in model.query_embed([text])][0]


def build_embedder(provider: EmbeddingProvider, model_name: str) -> Embedder:
    if provider == "hashed":
        return HashedEmbedder()
    fast = FastEmbedEmbedder(model_name)
    if provider == "fastembed":
        return fast
    try:
        fast.warm_up()
    except Exception as exc:  # noqa: BLE001 - any failure (import, download, ONNX) means fall back
        log.warning("fastembed unavailable (%s); falling back to hashed embedder", exc.__class__.__name__)
        return HashedEmbedder()
    return fast
```

```python
"""Citation IDs are chunk IDs. A citation can only point at a stored chunk (spec §8)."""

from collections.abc import Iterable

from gridline.rag.models import Citation, StoredChunk


def citation_id(document_id: str, section_id: str) -> str:
    return f"{document_id}#{section_id}"


def build_citation(chunk: StoredChunk) -> Citation:
    return Citation(
        id=chunk.chunk_id,
        document_title=chunk.document_title,
        section=chunk.section,
        source=chunk.source,
        text=chunk.text,
    )


def format_citation(c: Citation) -> str:
    return f"[{c.id}] {c.document_title} — {c.section} ({c.source})"


def validate_citation_ids(cited: Iterable[str], allowed: Iterable[str]) -> list[str]:
    """Return the cited IDs that were not in `allowed`, deduplicated, in first-seen order."""
    allowed_set = set(allowed)
    unknown: list[str] = []
    for cid in cited:
        if cid not in allowed_set and cid not in unknown:
            unknown.append(cid)
    return unknown
```

```python
"""Persistence and vector search for documents and chunks on PostgreSQL + pgvector (spec §4, §8)."""

from typing import Any

from sqlalchemy import Select, delete, func, literal, or_, select
from sqlalchemy.dialects.postgresql import ARRAY, Text, insert
from sqlalchemy.ext.asyncio import AsyncSession, async_sessionmaker

from gridline.db.models import Chunk, Document
from gridline.rag.citations import build_citation
from gridline.rag.models import (
    ChunkDraft,
    CorpusDocument,
    DocumentKind,
    DocumentRecord,
    RetrievalFilters,
    RetrievedChunk,
    StoredChunk,
)


class ChunkStore:
    def __init__(self, sessions: async_sessionmaker[AsyncSession]) -> None:
        self._sessions = sessions

    async def upsert_document(
        self, doc: CorpusDocument, chunks: list[ChunkDraft], embeddings: list[list[float]], embedding_model: str
    ) -> None:
        if len(chunks) != len(embeddings):
            raise ValueError(f"{doc.slug}: {len(chunks)} chunks but {len(embeddings)} embeddings")
        values: dict[str, Any] = {
            "id": doc.slug, "title": doc.title, "kind": doc.kind.value, "source": doc.source,
            "source_path": doc.source_path, "date": doc.date, "zone_ids": doc.zone_ids, "hazards": doc.hazards,
            "content_hash": doc.content_hash, "embedding_model": embedding_model, "metadata": doc.metadata,
            "ingested_at": func.now(),
        }
        async with self._sessions() as session, session.begin():
            stmt = insert(Document).values(**values)
            update_cols = {k: v for k, v in values.items() if k != "id"}
            await session.execute(stmt.on_conflict_do_update(index_elements=[Document.id], set_=update_cols))
            await session.execute(delete(Chunk).where(Chunk.document_id == doc.slug))
            if chunks:
                await session.execute(
                    insert(Chunk),
                    [
                        {
                            "id": c.chunk_id, "document_id": c.document_id, "section_id": c.section_id,
                            "section_title": c.section_title, "position": c.position, "text": c.text,
                            "embedding": vec, "kind": doc.kind.value, "zone_ids": doc.zone_ids,
                            "hazards": doc.hazards, "metadata": c.metadata,
                        }
                        for c, vec in zip(chunks, embeddings, strict=True)
                    ],
                )

    async def delete_document(self, document_id: str) -> bool:
        async with self._sessions() as session, session.begin():
            result = await session.execute(delete(Document).where(Document.id == document_id))
            return (result.rowcount or 0) > 0

    async def list_documents(self) -> list[DocumentRecord]:
        async with self._sessions() as session:
            rows = await session.execute(
                select(Document.id, Document.title, Document.kind, Document.content_hash, Document.embedding_model)
                .order_by(Document.id)
            )
            return [
                DocumentRecord(id=r.id, title=r.title, kind=DocumentKind(r.kind), content_hash=r.content_hash,
                               embedding_model=r.embedding_model)
                for r in rows
            ]

    async def embedding_models(self) -> set[str]:
        async with self._sessions() as session:
            rows = await session.execute(select(Document.embedding_model).distinct())
            return {r[0] for r in rows}

    async def count_chunks(self) -> int:
        async with self._sessions() as session:
            return (await session.execute(select(func.count()).select_from(Chunk))).scalar_one()

    async def get_chunk(self, chunk_id: str) -> StoredChunk | None:
        async with self._sessions() as session:
            row = (await session.execute(_base_select().where(Chunk.id == chunk_id))).first()
            return _to_stored(row) if row else None

    async def search(
        self, query_embedding: list[float], *, top_k: int, filters: RetrievalFilters | None = None
    ) -> list[RetrievedChunk]:
        if top_k <= 0:
            return []
        distance = Chunk.embedding.cosine_distance(query_embedding)
        stmt = _base_select().add_columns((literal(1.0) - distance).label("similarity"))
        stmt = _apply_filters(stmt, filters).order_by(distance).limit(top_k)
        async with self._sessions() as session:
            rows = (await session.execute(stmt)).all()
        results: list[RetrievedChunk] = []
        for row in rows:
            stored = _to_stored(row)
            results.append(RetrievedChunk(**stored.model_dump(), similarity=float(row.similarity), citation=build_citation(stored)))
        return results


def _base_select() -> Select[Any]:
    return (
        select(
            Chunk.id, Chunk.document_id, Document.title.label("document_title"), Chunk.section_id,
            Chunk.section_title, Document.source, Chunk.kind, Chunk.zone_ids, Chunk.hazards, Chunk.text,
            Chunk.metadata_.label("metadata"),
        )
        .join(Document, Document.id == Chunk.document_id)
    )


def _apply_filters(stmt: Select[Any], filters: RetrievalFilters | None) -> Select[Any]:
    if filters is None:
        return stmt
    if filters.kinds:
        stmt = stmt.where(Chunk.kind.in_([k.value for k in filters.kinds]))
    if filters.document_ids:
        stmt = stmt.where(Chunk.document_id.in_(filters.document_ids))
    if filters.hazards:
        wanted = literal(filters.hazards, type_=ARRAY(Text))
        stmt = stmt.where(or_(Chunk.hazards.overlap(wanted), func.cardinality(Chunk.hazards) == 0))
    if filters.zone_ids:
        wanted = literal(filters.zone_ids, type_=ARRAY(Text))
        stmt = stmt.where(or_(Chunk.zone_ids.overlap(wanted), func.cardinality(Chunk.zone_ids) == 0))
    return stmt


def _to_stored(row: Any) -> StoredChunk:
    return StoredChunk(
        chunk_id=row.id, document_id=row.document_id, document_title=row.document_title, section_id=row.section_id,
        section=row.section_title, source=row.source, kind=DocumentKind(row.kind), zone_ids=list(row.zone_ids),
        hazards=list(row.hazards), text=row.text, metadata=dict(row.metadata),
    )
```

```python
"""The one retrieval entry point: retrieve(query, filters, top_k) -> evidence with citations (spec §8)."""

import asyncio

from gridline.rag.embedder import Embedder
from gridline.rag.models import EmbeddingModelMismatchError, RetrievalFilters, RetrievedChunk
from gridline.rag.store import ChunkStore


class Retriever:
    def __init__(self, store: ChunkStore, embedder: Embedder) -> None:
        self._store = store
        self._embedder = embedder
        self._checked_model = False

    async def retrieve(
        self,
        query: str,
        filters: RetrievalFilters | None = None,
        top_k: int = 8,
        min_similarity: float = 0.0,
    ) -> list[RetrievedChunk]:
        if not query.strip():
            raise ValueError("query must not be blank")
        if top_k <= 0:
            raise ValueError("top_k must be positive")
        await self._ensure_same_embedding_model()
        vector = await asyncio.to_thread(self._embedder.embed_query, query)
        results = await self._store.search(vector, top_k=top_k, filters=filters)
        return [r for r in results if r.similarity >= min_similarity]

    async def _ensure_same_embedding_model(self) -> None:
        if self._checked_model:
            return
        indexed = await self._store.embedding_models()
        if indexed and indexed != {self._embedder.name}:
            raise EmbeddingModelMismatchError(
                f"corpus was indexed with {sorted(indexed)} but the live embedder is '{self._embedder.name}'; "
                "run `uv run gridline-ingest` again with the current EMBEDDING_PROVIDER"
            )
        if indexed:
            self._checked_model = True
```

```python
"""Ingest the corpus: load, chunk, embed, store. Console script `gridline-ingest` (spec §9)."""

import argparse
import asyncio
import logging
import sys
import time
from collections.abc import Sequence
from pathlib import Path
from typing import Literal, cast

from gridline.config import EmbeddingProvider, Settings
from gridline.db.engine import create_engine, session_factory
from gridline.db.schema import create_schema, drop_schema
from gridline.rag.chunker import chunk_document
from gridline.rag.corpus import load_corpus
from gridline.rag.embedder import Embedder, build_embedder
from gridline.rag.models import CorpusError, IngestReport
from gridline.rag.store import ChunkStore

log = logging.getLogger(__name__)
EMBED_BATCH = 64


async def ingest(*, database_url: str, corpus_dir: Path, embedder: Embedder, reset: bool = False) -> IngestReport:
    started = time.perf_counter()
    docs = load_corpus(corpus_dir)  # raises CorpusError before any DB work
    engine = create_engine(database_url)
    try:
        if reset:
            await drop_schema(engine)
        await create_schema(engine)
        store = ChunkStore(session_factory(engine))
        existing = {r.id: r for r in await store.list_documents()}
        report = IngestReport(embedding_model=embedder.name)
        for doc in docs:
            prior = existing.pop(doc.slug, None)
            if prior and prior.content_hash == doc.content_hash and prior.embedding_model == embedder.name:
                report.documents_unchanged += 1
                continue
            chunks = chunk_document(doc)
            vectors: list[list[float]] = []
            for i in range(0, len(chunks), EMBED_BATCH):
                batch = [c.embedding_text for c in chunks[i : i + EMBED_BATCH]]
                vectors.extend(await asyncio.to_thread(embedder.embed_documents, batch))
            await store.upsert_document(doc, chunks, vectors, embedder.name)
            report.chunks_written += len(chunks)
            if prior:
                report.documents_updated += 1
            else:
                report.documents_added += 1
            log.info("ingested %s (%d chunks)", doc.slug, len(chunks))
        for stale_id in existing:
            await store.delete_document(stale_id)
            report.documents_removed += 1
        report.duration_s = round(time.perf_counter() - started, 3)
        return report
    finally:
        await engine.dispose()


def _parse_args(argv: Sequence[str] | None) -> argparse.Namespace:
    parser = argparse.ArgumentParser(prog="gridline-ingest", description="Ingest the Nandipur knowledge base.")
    parser.add_argument("--corpus", type=Path, default=None, help="corpus directory (default: CORPUS_DIR)")
    parser.add_argument("--reset", action="store_true", help="drop and recreate the documents/chunks tables first")
    parser.add_argument("--provider", choices=["auto", "fastembed", "hashed"], default=None)
    parser.add_argument("-v", "--verbose", action="store_true")
    return parser.parse_args(argv)


def main(argv: Sequence[str] | None = None) -> int:
    args = _parse_args(argv)
    logging.basicConfig(level=logging.INFO if args.verbose else logging.WARNING, format="%(levelname)s %(message)s")
    settings = Settings()
    provider = cast(EmbeddingProvider, args.provider) if args.provider else settings.embedding_provider
    corpus_dir = cast(Path | None, args.corpus) or settings.resolved_corpus_dir()
    embedder = build_embedder(provider, settings.embedding_model)
    try:
        report = _run(ingest(database_url=settings.database_url, corpus_dir=corpus_dir, embedder=embedder, reset=bool(args.reset)))
    except CorpusError as exc:
        print(f"corpus error: {exc}", file=sys.stderr)
        return 1
    for key, value in report.model_dump().items():
        print(f"{key}: {value}")
    return 0


def _run[T](coro: "asyncio.Future[T] | Coroutine[Any, Any, T]") -> T:
    if sys.platform == "win32":
        with asyncio.Runner(loop_factory=asyncio.SelectorEventLoop) as runner:
            return runner.run(coro)
    return asyncio.run(coro)
```
